I work on the theory and algorithms of **anomaly detection**: isolation-based and kernel-based methods, streaming data, and **text anomaly detection** at both the document level and the token level.

## 🔥 PyTextAD

**[PyTextAD](https://github.com/charles-cao/pytextad)**: a Python library for document-level and token-level text anomaly detection.

[![PyPI](https://img.shields.io/pypi/v/pytextad?style=flat-square)](https://pypi.org/project/pytextad/)
[![Downloads](https://img.shields.io/pypi/dm/pytextad?style=flat-square)](https://pypi.org/project/pytextad/)
[![Stars](https://img.shields.io/github/stars/charles-cao/pytextad?style=flat-square)](https://github.com/charles-cao/pytextad)
[![Docs](https://img.shields.io/badge/docs-readthedocs-blue?style=flat-square)](https://pytextad.readthedocs.io)
[![Demo](https://img.shields.io/badge/🤗%20demo-Hugging%20Face-yellow?style=flat-square)](https://huggingface.co/spaces/Charles-Cao/pytextad)

```bash
pip install pytextad
```

- 23 detectors behind one `fit` / `decision_function` / `predict` interface
- Token-level scoring for any detector, rolled up into document scores
- Six benchmark datasets with a label for every word
- Wraps PyOD models out of the box
