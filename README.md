### 🔥 Featured Project: PyTextAD

<table>
<tr>
<td width="60%">

**[PyTextAD](https://github.com/charles-cao/pytextad)** is a Python library for document-level and token-level text anomaly detection.

- 🧩 **23 detectors**, one `fit` / `decision_function` / `predict` interface
- 🔬 **Token-level** scoring for any detector, rolled up into document scores
- 📊 **Six benchmarks** with a label for every word
- 🔌 Wraps **PyOD** models out of the box

```bash
pip install pytextad
```
